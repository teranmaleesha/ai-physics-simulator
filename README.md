# ⚛️ AI-Powered Radioactive Decay & Physics Simulator

An interactive web application built with **Python**, **Streamlit**, and **Matplotlib** that simulates radioactive decay laws, half-life calculations, and predictive physical science modeling. Designed for students, researchers, and physics enthusiasts to visualize nuclear physics concepts dynamically.

---

## 🚀 Features

- **Isotope Selection:** Choose between Carbon-14, Uranium-238, Radon-222, or custom isotopes with pre-configured half-lives.
- **Real-time Simulation:** Adjust initial nuclei count, decay constants, and time parameters using interactive sliders.
- **Exponential Decay Modeling:** Visualizes remaining and decayed nuclei over time with precise mathematical calculations and dynamic Matplotlib plots.
- **AI & Physics Insights:** Generates analytical summaries and educational insights based on nuclear decay principles.

---

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **Framework:** Streamlit (Web UI)
- **Data Processing:** NumPy
- **Visualization:** Matplotlib
